Thanks to all the developers for the open-source resources above.
I packaged it with WorkBuddy for easier use.
When the administrator runs the EXE file, a web page will pop up. Once only green dots are shown on the web page, refresh the WeChat Channels page, then you can click the download button in the upper right corner.
Real-time recording is available even after the WeChat Channels live stream is closed, and recording from multiple live rooms is supported.
